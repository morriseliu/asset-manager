# 全能资产管家

单文件个人资产 / 投资 / 记账 / 待还管理，做成了可安装的 PWA（可添加到手机主屏幕、离线打开）。

- 数据默认只存在本机浏览器（localStorage）。
- 可选：设置 → 多设备同步，用自己的 GitHub 令牌（仅 gist 权限）把数据同步到自己账号下的**私密 Gist**。令牌只保存在本设备浏览器，不在本仓库中。
- 行情接口（腾讯、天天基金、Coinbase、Binance 等）始终直接走网络，不缓存。

## 快捷记账（iPhone 不打开网页也能记一笔）

原理：iOS「快捷指令」用一次 GitHub API 请求，在你的同步私密 Gist 里新建一个 `quick_<时间>.txt` 小文件（第1行金额、第2行分类、第3行备注、可选第4行账户名；金额前加 `+` 表示收入）。快捷指令不需要读取或解析 JSON，多笔同时记也不会互相覆盖。
下次打开本页或自动同步时，app 会把这些文件导入账本（按文件名去重，不会重复入账），上传账本成功后再删除已导入的文件；期间新记的不会被删。导入后提示「已导入 N 笔快捷记账」。

需要先在「设置 → 多设备同步」里填好令牌，Gist ID 显示在「设置 → 快捷记账」里。

### 建立快捷指令「记一笔」

1. 准备令牌：打开 https://github.com/settings/tokens/new?scopes=gist ，只勾选 gist，有效期选 No expiration，生成后复制 `ghp_` 开头的令牌（可用和多设备同步同一个）。
2. 打开「快捷指令」App，点右上角＋新建，命名「记一笔」。
3. 添加「要求输入」：输入类型选「数字」，提示写「金额」。
4. 添加「列表」：每行一个分类（餐饮、交通、购物、日用、娱乐、住房、医疗、通讯、人情、其他、工资、奖金、理财、退款、其他收入）；再添加「从列表中选取」。
5. （可选）添加「要求输入」：类型「文本」，提示写「备注」。
6. 添加「文本」，内容分三行：第1行插入变量「提供的输入」（金额），第2行插入「所选项目」，第3行插入备注那一步的「提供的输入」（没有备注就只写两行）。
7. 添加「获取 URL 的内容」：URL 填 `https://api.github.com/gists/<你的 Gist ID>`；点「显示更多」，方法选 PATCH；头部添加 `Authorization`，值填 `Bearer ghp_你的令牌`；请求体选 JSON。
8. 请求体里添加字段，类型「词典」，键填 `files`；在里面再添加一个「词典」字段，键填 `quick_` + 变量「当前日期」+ `.txt`（点日期变量 → 日期格式「自定」→ `yyyyMMdd-HHmmss-SSS`）；在最里层词典添加「文本」字段，键 `content`，值插入第6步的「文本」。
9. 添加「显示通知」：`已记账 ¥` + 金额变量。点「完成」，运行一次测试。

### 触发方式

- 轻点背面：设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「记一笔」。
- 小组件：长按桌面或锁屏 → 添加小组件 → 快捷指令 → 选「记一笔」。
- Apple Pay 付款后自动记：快捷指令 → 自动化 → ＋ →「交易」，选卡片，选「立即运行」，新建快捷指令：第3步改用「快捷指令输入」的「金额」，备注用「商家」，其余同上。（国内部分银行卡不支持「交易」触发。）

令牌保存在快捷指令里，请不要把这个快捷指令分享给别人。
