# 全能资产管家

单文件个人资产 / 投资 / 记账 / 待还管理，做成了可安装的 PWA（可添加到手机主屏幕、离线打开）。

- 数据默认只存在本机浏览器（localStorage）。
- 可选：设置 → 多设备同步，用自己的 GitHub 令牌（仅 gist 权限）把数据同步到自己账号下的**私密 Gist**。令牌只保存在本设备浏览器，不在本仓库中。
- 行情接口（腾讯、天天基金、Coinbase、Binance 等）始终直接走网络，不缓存。

## 快捷记账「记一笔」（付完款敲两下手机背面）

页面：https://morriseliu.github.io/asset-manager/quick.html

打开即是大号数字键盘：按金额 → 点分类，一下就保存（可选备注、支出/收入切换），5 秒内可撤销。

- 开启了「多设备同步」（本浏览器存有令牌）时：每笔写成私密 Gist 里的一个 `quick_<时间>.txt` 小文件（一次 PATCH，多笔不会互相覆盖）。主 App 打开/同步时导入账本（按 qid 去重，不会重复入账），上传成功后删除已导入的文件。离线时先排队，下次打开记一笔页或联网时自动上传。
- 没开启同步时：直接记入当前浏览器的账本，并在页面上提示「粘贴令牌」开启同步（只需一次）。
- iOS 快捷指令「打开 URL」用 Safari 打开页面，Safari 与主屏幕 App 的本地存储是分开的，所以 Safari 里也要填一次同步令牌（页面会提示）。
- 可选预填：`quick.html?amt=38&note=星巴克&type=income`。

### iPhone 设置（3 步）

1. 快捷指令 App → 右上角 ＋ → 添加「打开 URL」→ 粘贴上面的链接 → 完成。
2. 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选这个快捷指令。
3. （可选）快捷指令 → 自动化 → ＋ → 钱包 → 选卡 → 立即运行 → 打开 URL（同一个链接）。

也可以 Safari 打开链接 → 分享 →「添加到主屏幕」。

### 高级：自建快捷指令直接写 Gist

收件箱文件内容：多行文本（第1行金额，前加 `+` 为收入；第2行分类；第3行备注；第4行账户名），或 `38|餐饮|午饭`，或 JSON。

### 备用：网址快捷记账

打开 `https://morriseliu.github.io/asset-manager/?add=1&amt=38&cat=餐饮&note=午饭` 会立刻记一笔并清掉网址参数（不需要同步）。可选参数：`type=income`、`acc=账户名`、`date=2026-10-25`、`id=唯一编号`（防重复）。
