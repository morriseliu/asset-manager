USDT 永续资金费

只读 Gate 公开的 USDT 永续行情，在这里手工记账。这一版只合计资金费和手填手续费，不含开平仓价差，不是交易盈亏。不写入持仓、账本、外汇，也不计入总资产。

怎么算、哪些不算

只估算 USDT 本位永续。不绑定账户，不读取持仓、委托、成交或资金流水，也不保存密钥。
名义价值 = 标记价 × 张数 × 合约乘数。做多且费率为正记负数（要付），做空且费率为正记正数（会收）；费率为负则反过来。杠杆只展示，不改变名义。
每个结算时点用当时的张数，张数为 0 就跳过。填「币」时按合约乘数换成张。
费率只用公开已结算记录，时间以返回的 t 为准，不按 8 小时或当前周期补历史。一次大约 30 天，再用更早一页往前翻；比最早一条更早的留空。合约上的当前资金费率是下一期，还没结算，不计入。
标记价取该分钟标记 K 线的开盘价。没有就留空，可以手填。乘数、标记价，以及第一次记下时的 USDT 汇率锁在这一行上。
交易手续费另记，支出为负、返佣为正。公开的挂单/吃单费率不会当成你的手续费。
填了手工实际就用手工实际，否则用估计（公开费率 × 标记价近似 × 手工仓位）。费用合计 = 资金费 + 交易手续费，不含开平仓价差，不是交易盈亏。结算前后 5 秒内改过数量的可以不计入。

说明

• 股票/港股/美股：腾讯行情（script 通道）
• 基金：天天基金估值/净值接口
• 虚拟货币：Coinbase、Binance 等并行行情
• 添加持仓时输入代码或名称即可，类型和币种自动识别
• 投资账户 = 持仓市值 + 闲钱。买入、加仓、定投从闲钱扣，卖出、减仓、清仓回到闲钱；闲钱可与银行卡等账户互转（只能转出闲钱）。互转记在明细账本，不算收入、支出，也不算投资盈亏
• 外汇交易账户可绑定交易复盘：余额自动等于复盘账户（美元），每日盈亏记入账本和盈亏统计，入金出金按转账处理
• 每天北京时间 6:00 后打开 App，自动记录上一交易日收盘盈亏；今日盈亏 = 数量 ×（现价 − 前收盘价）。美股在北京时间次日 06:00 前仍算同一个交易日；休市日记 0。打开应用和回到前台会自动刷新行情
• USDT 永续资金费在「我的 → 设置」手工估算：只读公开行情，不计入持仓、账本、外汇和总资产
• 数据默认存在本机浏览器；在「我的 → 设置 → 多设备同步」开启后，也会保存到你自己的 GitHub 私密 Gist
